# GitHub Build or Reuse v1.2.3

This patch release completes the first Agent Plugins 1.0 portability pilot with evidence from real current clients while preserving the existing Agent Skill and skills.sh install paths.

## Multi-host compatibility evidence

The repository CI now pins and verifies:

- **GitHub Copilot CLI 1.0.83** — marketplace add/browse/install/list;
- **OpenAI Codex CLI 0.153.4** — native root Agent Plugin marketplace install with installed/enabled state;
- **Claude Code 2.1.263** — strict plugin validation, local marketplace installation and installed-plugin discovery;
- **Gemini CLI 0.58.0** — extension validation/install/discovery and preservation of the canonical Agent Skill;
- **GitHub Agentic Workflows 0.88.4** — experimental `plugins:` compile-time consumption with `v1.2.2` resolved to its exact commit in generated workflow state.

Cursor remains explicitly classified as vendor-documented native Agent Plugins support without repository-executed headless install evidence.

These are package/install/compile results. They do not claim model-driven behavioral parity; that stronger lifecycle work continues in #35.

## Adapter hardening

Real Claude Code validation exposed an unnecessary cross-host `interface` object in the generated Claude adapter. The generator now emits a minimal Claude-native manifest while still deriving all runtime behavior from the same canonical:

`skills/github-build-or-reuse/SKILL.md`

No platform-specific copy of the skill was introduced.

## Release supply-chain hardening

The repository now includes an importable immutable release-tag ruleset recipe derived from GitHub's official ruleset recipes. It targets `refs/tags/v*` and blocks update, deletion and non-fast-forward changes.

The recipe, validator and idempotent admin helper are versioned, but **live activation still requires repository administration permission** and remains tracked in #32. This release does not claim the server-side ruleset is already active.

## Distribution stability

The following remain unchanged:

- repository: `ghspain/github-build-or-reuse`;
- canonical skill: `github-build-or-reuse`;
- canonical path: `skills/github-build-or-reuse/SKILL.md`;
- skills.sh / `npx skills` discovery path;
- USE / CONTRIBUTE / FORK / BUILD decision behavior;
- no mandatory custom MCP dependency for this capability.
