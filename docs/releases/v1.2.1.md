# v1.2.1 — Packaging, CI and behavioral eval convergence

This patch release keeps the **GitHub Build or Reuse** runtime contract unchanged while making its standalone distribution and regression testing substantially stronger.

## What changed

- Cross-agent manifests for Agent Plugins, Codex, Claude Code, Cursor and Gemini are now deterministically generated from one canonical packaging configuration and repository version.
- GitHub Actions now enforce immutable action SHAs, `persist-credentials: false`, explicit permissions and timeouts, with Dependabot tracking Actions updates.
- Intrinsic behavior is now protected by a canonical Waza suite covering research-before-build, evidence-backed reuse verdicts, explicit discovery bypass, trivial-work boundaries and unavailable-tool disclosure.
- Legacy skill-local JSON eval fixtures were removed; the canonical behavioral suite now lives at `evals/github-build-or-reuse/`.

## Compatibility

There is **no functional decision-model change** from v1.2.0. `USE`, `CONTRIBUTE`, `FORK`, and `BUILD` semantics and runtime instructions remain the same. The version bump lets stable downstream mirrors consume the cleaned payload and updated platform metadata through normal release tracking.

## Install

```bash
gh skill install ghspain/github-build-or-reuse github-build-or-reuse@v1.2.1
```

Or with the cross-agent skills CLI:

```bash
npx skills@latest add ghspain/github-build-or-reuse --skill github-build-or-reuse
```
