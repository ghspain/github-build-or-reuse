# GitHub repository configuration

Repository-level GitHub settings are managed centrally by GitHub Community Spain using [Safe Settings](https://github.com/github-community-projects/safe-settings).

The source of truth lives in the organization's private repository-administration configuration rather than in this project. This repository intentionally does not vendor a custom settings workflow or administrative script.

Managed configuration includes:

- repository description and discovery topics;
- GitHub's native `delete branch on merge` setting;
- project labels.

This keeps platform configuration centralized and reuses the established Safe Settings project instead of maintaining repository-specific automation.
